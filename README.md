# DeepSeek Harness 桌面版

把 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的网页版（`npx @deepseek-ai/dsh web`）封装成的 Windows 桌面程序：蓝鲸图标 + `Ctrl+Alt+D` 全局热键，自带 Node 运行时，解压即用。

## 📦 直接下载（推荐）
去 **[Releases](https://github.com/sv8vkwmfr7-create/agent/releases)** 下载 `DeepSeekHarness-win64.zip`，解压后双击 `DeepSeekHarness.exe` 即可。

## 📂 源码
本仓库的**源码在 [`deepseek-harness` 分支](https://github.com/sv8vkwmfr7-create/agent/tree/deepseek-harness)**，请切换到该分支查看与构建。

## 🔧 版本
版本以 Git tag（`v1.0.0` 等）+ GitHub Release 管理；每个版本的预编译包作为对应 Release 的附件提供。
